# website-rs

Une boîte à outils Rust modulaire pour des sites et API plus sûrs : chiffrement, limites de requêtes, routage, cache, en-têtes de sécurité, rate limiting, CAPTCHA et CSRF.

Des paquets Python, JavaScript et TypeScript sont disponibles dans `packages/` pour une adoption progressive.

```bash
cargo test --workspace
```

Consultez l'[intégration](INTEGRATION.md), l'[architecture](ARCHITECTURE.md) et le [README principal](../README.md).
