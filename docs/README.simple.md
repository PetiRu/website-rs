# website-rs

A small security module set for existing and new sites. It provides authenticated encryption, request limits, security headers, rate limiting, one-time CAPTCHA examples, and CSRF token primitives.

The project includes Rust crates plus companion Python, JavaScript, and TypeScript packages. Add one layer first, then expand as your site needs grow.

Read [integration](INTEGRATION.md), [architecture](ARCHITECTURE.md), and [security notes](CAPTCHA.md).
