# website-rs

Модульный Rust-набор для более безопасных сайтов и API: шифрование, лимиты запросов, маршрутизация, кэш, security-заголовки, rate limiting, CAPTCHA и CSRF.

Пакеты Python, JavaScript и TypeScript в `packages/` позволяют постепенно добавить функции в существующий проект.

```bash
cargo test --workspace
```

См. [интеграцию](INTEGRATION.md), [архитектуру](ARCHITECTURE.md) и [главный README](../README.md).
