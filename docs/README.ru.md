# website-rs

Модульный Rust-проект с упором на безопасность для современных веб-сервисов.

## Обзор

`website-rs` объединяет базовые элементы, которые обычно создают вручную для безопасных веб-приложений:

- аутентифицированное шифрование
- проверка запросов и ограничения размеров
- маршрутизация с кэшированием
- защита веб-приложения
- типизированная конфигурация
- структурированная наблюдаемость

## Основные модули

- `website-encryption`: шифрование AES-256-GCM
- `website-api`: типы запроса и ответа
- `website-cache`: TTL-кэш в памяти
- `website-router`: маршрутизация и ключи кэша
- `website-protection`: заголовки, origin-проверки, rate limiting
- `website-config`: конфигурация через переменные окружения
- `website-observability`: логирование и tracing

## Быстрый старт

```bash
cargo test --workspace
cargo run --manifest-path examples/secure-service/Cargo.toml
```

## Безопасность

- Не храните ключи в репозитории.
- Используйте HTTPS/TLS в продакшене.
- Проводите ротацию и миграцию ключей контролируемо.
- Проверка на стороне клиента не является границей безопасности.
