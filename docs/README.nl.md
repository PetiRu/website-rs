# website-rs

Een modulaire Rust-toolkit voor veiligere websites en API's.

De workspace biedt geauthenticeerde encryptie, requestlimieten, routing, caching, beveiligingsheaders, rate limiting en optionele eenmalige CAPTCHA-uitdagingen. Voeg alleen de crates toe die je nodig hebt.

```bash
cargo test --workspace
```

Lees de [integratiehandleiding](INTEGRATION.md), [architectuur](ARCHITECTURE.md) en het [hoofd-README](../README.md). CAPTCHA vervangt geen TLS, autorisatie of professionele botbescherming.
