# website-rs

Ett modulärt Rust-verktyg för säkrare webbplatser och API:er med kryptering, request-gränser, routing, cache, säkerhetsheaders, rate limiting, CAPTCHA och CSRF.

Python-, JavaScript- och TypeScript-paket finns i `packages/` för stegvis integration i befintliga projekt.

```bash
cargo test --workspace
```

Läs [integrationsguiden](INTEGRATION.md), [arkitekturen](ARCHITECTURE.md) och [huvud-README](../README.md).
