# website-rs

Eine modulare Rust-Bibliothek für sicherere Websites und APIs mit Verschlüsselung, Request-Limits, Routing, Cache, Security-Headern, Rate Limiting, CAPTCHA und CSRF-Grundlagen.

Leichte Python-, JavaScript- und TypeScript-Pakete in `packages/` ermöglichen die schrittweise Integration in bestehende Projekte.

```bash
cargo test --workspace
```

Siehe [Integration](INTEGRATION.md), [Architektur](ARCHITECTURE.md) und [Haupt-README](../README.md).
