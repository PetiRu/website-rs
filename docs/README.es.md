# website-rs

Un kit Rust modular para sitios web y APIs más seguros. Incluye cifrado autenticado, límites de solicitudes, routing, caché, headers de seguridad, rate limiting, CAPTCHA y protección CSRF.

También ofrece paquetes ligeros para Python, JavaScript y TypeScript en `packages/`, fáciles de añadir a sitios existentes.

```bash
cargo test --workspace
```

Consulta la [integración](INTEGRATION.md), la [arquitectura](ARCHITECTURE.md) y el [README principal](../README.md).
