# website-rs

Một bộ công cụ Rust mô-đun cho website và API an toàn hơn, gồm mã hóa, giới hạn request, định tuyến, cache, security headers, rate limiting, CAPTCHA và CSRF.

Các gói Python, JavaScript và TypeScript trong `packages/` giúp tích hợp dần vào dự án hiện có.

```bash
cargo test --workspace
```

Xem [tích hợp](INTEGRATION.md), [kiến trúc](ARCHITECTURE.md) và [README chính](../README.md).
