# website-rs

Модульний набір Rust для безпечних вебсайтів і API.

Містить автентифіковане шифрування, обмеження запитів, маршрутизацію, кеш, захисні HTTP-заголовки, rate limiting і додаткові одноразові CAPTCHA-виклики. Модулі можна підключати окремо до наявного проєкту.

```bash
cargo test --workspace
```

Дивіться [інтеграцію](INTEGRATION.md), [архітектуру](ARCHITECTURE.md) та [головний README](../README.md). CAPTCHA не замінює TLS, авторизацію або повноцінний захист від ботів.
